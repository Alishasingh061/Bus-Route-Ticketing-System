# 🚌 Bus Route & Ticketing System

A console-based Bus Route and Ticketing Management System developed using Java.

## 📌 About the Project
This project helps users manage bus routes, book tickets, search tickets, cancel bookings, and check seat availability through a menu-driven interface.

## ✨ Features
- View Bus Routes
- Book Tickets
- Search Tickets
- Cancel Tickets
- Check Next Stop
- View Seat Availability
- Waiting Queue Management
- Save Data Using File Handling

## 🛠️ Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Collections
- File Handling

## ▶️ How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the Java file:

```bash
javac Main.java
```

5. Run the project:

```bash
java Main
```
